# Lisensi dan pemberitahuan data

Lisensi kode proyek perlu diputuskan oleh pemilik repositori sebelum publikasi (misalnya MIT, Apache-2.0, atau lisensi lain). File ini tidak menetapkan lisensi untuk dataset eksternal.

Data dummy di `data/dummy/` dibuat sintetis untuk demonstrasi dan pengujian pipeline. Untuk dataset eksternal, patuhi lisensi, atribusi, batas redistribusi, dan ketentuan penggunaan dari pemilik dataset masing-masing. Jangan menyertakan file dataset mentah ke GitHub sebelum hak redistribusinya dipastikan.
